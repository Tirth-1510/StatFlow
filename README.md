# Inventory Management System

## Overview
A full‑stack web application for managing product inventory, built with **Node.js/Express** on the backend and **React** on the frontend. It provides real‑time CRUD operations for items, user authentication, role‑based access, and responsive UI components.

## Features
- **User Authentication** with JWT and role‑based permissions (admin, manager, staff).
- **Inventory CRUD**: create, view, update, and delete products with quantity tracking.
- **Bulk Operations**: import/export CSV, bulk update via modal dialogs.
- **Dashboard Analytics**: visual summaries of stock levels and recent activity.
- **Responsive Design** using modern CSS (flexbox, grid) for desktop and mobile.
- **RESTful API** adhering to MVC structure (`controllers`, `models`, `routes`).
- **Environment configuration** using `.env` for secure credentials.
- **Testing utilities** for authentication and data validation.

## Installation
```bash
# Clone the repository
git clone https://github.com/yourusername/inventory-management-system.git
cd inventory-management-system

# Install backend dependencies
cd server
npm install

# Install frontend dependencies
cd ../frontend
npm install
```

## Configuration
Create a `.env` file in the `server` directory with the following keys (adjust values as needed):
```dotenv
PORT=5000
MONGODB_URI=mongodb://localhost:27017/inventorydb
JWT_SECRET=your_jwt_secret
```

## Running the Application
```bash
# Start backend server (listens on PORT)
cd server && npm start

# In another terminal, start the frontend dev server
cd frontend && npm run dev
```
The frontend will be available at `http://localhost:3000` (or the configured Vite port) and will proxy API requests to the backend.
